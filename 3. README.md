
# LIFO Using Verilog

## Description

This project implements a **LIFO (Last-In First-Out)** data structure using Verilog HDL.

A LIFO operates like a stack:

**Last Data Written → First Data Read**

For example, if the following values are pushed:

```text
10 → 20 → 30
```

The values are popped in the reverse order:

```text
30 → 20 → 10
```

## Files

```text
lifo/
├── lifo.v
├── lifo_tb.v
└── README.md
```

### `lifo.v`

Contains the RTL implementation of the LIFO stack.

### `lifo_tb.v`

Contains the simulation testbench used to verify PUSH and POP operations.

## Features

* 8-bit data width
* 8-entry stack
* PUSH operation
* POP operation
* Full flag
* Empty flag
* Synchronous reset
* Stack pointer

## Interface

| Signal  | Direction | Description              |
| ------- | --------- | ------------------------ |
| `clk`   | Input     | Clock signal             |
| `rst`   | Input     | Synchronous reset        |
| `push`  | Input     | Stores data into stack   |
| `pop`   | Input     | Removes data from stack  |
| `din`   | Input     | Input data               |
| `dout`  | Output    | Popped data              |
| `full`  | Output    | Indicates stack is full  |
| `empty` | Output    | Indicates stack is empty |

## LIFO Operation

### PUSH

When:

```text
push = 1
full = 0
```

the input data is stored at the current stack position.

Example:

```text
PUSH 10
PUSH 20
PUSH 30
```

Stack contents:

```text
TOP → 30
      20
      10
```

### POP

When:

```text
pop = 1
empty = 0
```

the top value is removed.

The output sequence will be:

```text
30
20
10
```

## Simulation

Using Icarus Verilog:

```bash
iverilog -o lifo_sim lifo.v lifo_tb.v
vvp lifo_sim
```

## Expected Output

The testbench performs these operations:

```text
PUSH 10
PUSH 20
PUSH 30
POP
POP
POP
```

The expected POP results are:

```text
DOUT = 30
DOUT = 20
DOUT = 10
```

A simplified representation is:

```text
Operation       Data       Stack
---------------------------------------
RESET           --         EMPTY
PUSH            10         10
PUSH            20         10, 20
PUSH            30         10, 20, 30
POP             30         10, 20
POP             20         10
POP             10         EMPTY
```

## Expected Result

```text
Input sequence : 10 → 20 → 30
Output sequence: 30 → 20 → 10
```

This confirms the **Last-In First-Out** behavior of the design.

## Conclusion

The Verilog LIFO implementation successfully performs PUSH and POP operations. The most recently pushed value is always the first value removed from the stack.
